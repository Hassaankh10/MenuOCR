# Icon provenance

Generated with the built-in image-generation tool, then copied into this project. The original PNG is preserved. macOS `sips` produced the sizes; the ICNS container embeds those PNGs without redrawing the artwork.

## Final prompt

Use case: logo-brand. Create a polished macOS application icon for MenuOCR, a local screenshot-to-text clipboard utility. Square 1024x1024 image. One large centered rounded-square blue-to-indigo ceramic/glass tile, with a restrained dimensional bevel, on transparent exterior. On the tile a bold white capture-viewfinder made of four rounded corner brackets surrounds three crisp horizontal text strokes; a small mint checkmark badge overlaps the lower-right portion of the viewfinder. Simple, exceptionally legible silhouette at 32px, balanced generous spacing, front-on orthographic composition, soft upper-left lighting, refined native Mac utility aesthetic. No words, letters, watermark, device mockup, extra objects or outer background. Tile occupies about 86% of canvas, transparent padding and subtle soft shadow outside.

The generated master is 1254×1254 with alpha; packaged icon sizes range from 16×16 to 1024×1024.
